# Drážďany 2026

Responzivní offline PWA průvodce pro adventní výlet do Drážďan **5.–6. prosince 2026**.

## Funkce

- sobotní a nedělní itinerář s časovou osou,
- lokální odškrtávání jednotlivých bodů,
- hlavní vánoční trhy a Stollenfest,
- doporučení MHD,
- schematická mapa fungující offline,
- soukromá sekce ukládaná pouze do `localStorage`,
- service worker + manifest pro instalaci jako PWA,
- bez frameworků a bez externích runtime závislostí.

## Soukromí

Repozitář je veřejný. Záměrně proto neobsahuje přesnou adresu ubytování, rezervační kódy, telefon hostitele, QR kódy ani jiné citlivé údaje z rezervací. Ty lze zadat přímo v aplikaci a zůstávají pouze v daném prohlížeči.

## GitHub Pages

Aplikace je připravena pro publikaci z kořene větve `main`.

**Settings → Pages → Deploy from a branch → main → /(root)**

Po zapnutí bude dostupná na:

https://l-ra.github.io/drazdany2026/

## Stav informací

Časy vlaků a základ itineráře vycházejí z rezervací pro výlet. Veřejné informace byly sestaveny z oficiálních zdrojů DVB, DB Bahnhof, Dresdner Stollenfest, Striezelmarkt, Advent auf dem Neumarkt, Mittelalter-Weihnacht im Stallhof a Weihnachtsmarkt an der Frauenkirche. Jízdní řády, ceny a otevírací doby je vhodné před cestou znovu ověřit.
